# How to use Pytorch with WSL and AMD GPUs (ROCM)

1- Install WSL and setup an Ubuntu instance (https://learn.microsoft.com/en-us/windows/wsl/install)

2- Install AMD drivers on your Ubuntu instance (https://rocm.docs.amd.com/projects/radeon-ryzen/en/latest/docs/install/installrad/wsl/install-radeon.html)

3- Install PyTorch on WSL with ROCM support (https://rocm.docs.amd.com/projects/radeon-ryzen/en/latest/docs/install/installrad/wsl/install-pytorch.html)
